# GitHub Pages — Trabalho Avaliativo 01

## Sobre o Projeto

Este repositório contém o site estático desenvolvido como **Trabalho Avaliativo 01** da disciplina **Desenvolvimento Web I**, do curso **Técnico Integrado em Informática para Internet**, sob orientação do professor **Hewerton Enes de Oliveira**.

O objetivo foi aprender, na prática, a publicar uma página web estática na internet, utilizando os conhecimentos de HTML e CSS já estudados em sala, e explorando por conta própria uma ferramenta nova: o **GitHub Pages**.

Mais do que um exercício técnico, este trabalho foi uma experiência de pesquisa e exploração — testar, errar, corrigir e, no final, ter um site real publicado, com endereço público acessível por qualquer pessoa.

## Processo de Desenvolvimento (Resumo)

1. **Pesquisa** — Estudo da documentação oficial do GitHub Pages, Git e HTML/CSS.
2. **Configuração** — Criação de conta no GitHub, criação do repositório público e instalação do Git localmente.
3. **Desenvolvimento** — Criação do `index.html` e `style.css`, com foco em semântica e responsividade.
4. **Versionamento** — Commits organizados a cada etapa do desenvolvimento (`git add`, `git commit`, `git push`).
5. **Publicação** — Ativação do GitHub Pages nas configurações do repositório (Settings → Pages → Branch `main`).
6. **Validação** — Teste do link público em aba anônima e em diferentes navegadores, confirmando o funcionamento.

📄 O passo a passo completo, com dificuldades encontradas e conceitos aprendidos, está documentado no [`RELATORIO.md`](./RELATORIO.md).
